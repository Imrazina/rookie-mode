# ROOKIE

1. Install or open Rookie.
2. Open **Formula 1**.
3. Press **TRY DEMO**.
4. Grant screen/system-audio permission if requested.

The demo uses the real audio playing on the computer. Press **⌃⇧R** on macOS or **Ctrl+Shift+R** on Windows to stop listening.

## macOS unsigned build

If macOS blocks Rookie, right-click **Rookie → Open**. Alternatively, use **System Settings → Privacy & Security → Open Anyway**.

## Windows unsigned build

If SmartScreen appears, choose **More info → Run anyway**.
